
# ASSIGNMENT ON PROGRAMMING

## QUESTION ONE

### 1. What is a Program?

A program is a set of instructions given to a computer to perform a particular task.

**Examples:**
- Calculator
- Microsoft Word
- Web browser

### 2. What is Programming?

Programming is the process of writing, testing, and executing instructions that tell a computer what to do.

**Example:**
Writing Python code to create a calculator.

### 3. What is a Programming Language?

A programming language is a language used by programmers to communicate with computers and give them instructions.

**Examples:**
- Python
- Java
- C++
- JavaScript
- PHP

## QUESTION TWO

### Differentiate Between Compiler and Interpreter

A compiler and an interpreter are both language translators that convert programming code into a form the computer can execute.

| Compiler | Interpreter |
|---|---|
| Translates the whole program before execution. | Translates and executes code one statement at a time. |
| Usually produces an executable or object file. | Usually executes code without creating a separate executable file. |
| Compiled programs generally execute faster. | Execution can be slower. |
| Reports errors during compilation. | Often reports errors when the affected statement is executed. |
| Example: GCC and Clang. | Example: CPython and Ruby interpreter. |

### Examples of Compiler

1. GCC (GNU Compiler Collection)
2. Clang
3. Microsoft C++ Compiler (MSVC)

### Examples of Interpreter

1. Python interpreter (CPython)
2. Ruby interpreter
3. PHP interpreter

## CONCLUSION

A program is a set of instructions given to a computer. Programming is the process of writing those instructions, while a programming language is used to communicate with computers. Compilers and interpreters translate programming code so computers can execute it.
